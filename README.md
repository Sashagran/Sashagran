### Featured project

#### [SocialGuard](https://github.com/Sashagran/Diploma) — explainable social engineering detector

A web service that analyzes suspicious messages and call transcripts for signs of social engineering and explains *why* a message is dangerous. Built as the practical part of my bachelor's thesis.

- Analyzes SMS, messenger and social network messages, emails, and call/voice transcripts
- Takes context into account: channel, claimed sender role, requested action
- Detects urgency, pressure, threats, impersonation, requests for codes and passwords, financial actions, remote access and more
- Rule engine for dangerous combinations of indicators, risk score from 0 to 100 with four risk levels
- Human-readable explanation and recommended safe action, local check history
- Built-in training game for practicing recognition of suspicious messages

`Python` `FastAPI` `Jinja2` `Pydantic` `Docker` `REST API`
